# :bullhorn: Known Issues

## Unity 6.7 Beta

PlayMaker 2 is incompatible with Unity 6000.7.0b2 due to a [Unity issue affecting precompiled plugins](https://discussions.unity.com/t/unity-6-7-beta-hash128-assembly-move-breaks-precompiled-plugins/1737635). Unity has confirmed that a fix is on the way.

## Unity 6.3

PlayMaker 2 is incompatible with Unity 6.3.0 through 6.3.4. If you use Unity 6.3, update to 6.3.5 or later.

## Entities Package

If you use the Entities package, use Unity 6.5 or later.

## :display: Light Theme

The GraphView does not yet support the light editor theme. Other parts of the PlayMaker UI may also need visual polish in light theme.

Please report any issues you encounter while using the light editor theme.
